# Перечень использованных библиотек и компонентов

Раздел 14 ЖКХ.md требует «перечень всех использованных библиотек и компонентов» — этот документ его закрывает. Версии зафиксированы на 21 сентября 2026 года; источники — `backend/requirements.txt`, `backend/requirements-worker.txt`, `backend/requirements-dev.txt`, `frontend/package.json` и локальное окружение `.venv` для офлайн-инструментов анализа данных и обучения модели. Все перечисленные лицензии — permissive/open source, без ограничений на использование в конкурсном прототипе.

## Примечание про SHAP-объяснения

Отдельный пакет `shap` не используется — объяснения прогноза считаются встроенным методом CatBoost (`model.get_feature_importance(pool, type="ShapValues")`), поэтому отдельной лицензии/зависимости для этого не требуется — она уже покрыта строкой CatBoost выше.
