# Frontend — три раздела диспетчера

React + TypeScript + Leaflet, без UI-фреймворка.
Разделы: «Риски» (список/карта + карточка), «Журнал», «Заявки» — см. `src/pages/`.

## Локальная разработка

```bash
cd frontend
npm install
npm run dev   # http://localhost:5173, проксирует /api на localhost:8000 (см. vite.config.ts)
```

Для локальной разработки backend должен быть поднят отдельно (см. `backend/README.md`,
`docker-compose.dev.yml`).

## Сборка/деплой

Собирается внутри Docker (`Dockerfile`: node → статика → nginx), локальный Node не нужен
для прод-разворачивания — только для разработки. Разворачивается как сервис `frontend` в
`docker-compose.yml`, за Caddy на проде (`deploy/Caddyfile`): `/api/*` → backend, всё
остальное → frontend.

## Что сделано (15 сентября 2026)

- Логин (JWT, роль хранится в `localStorage`), защищённые запросы через общий API-клиент.
- «Риски»: список с фильтром по статусу, переключение список/карта (Leaflet), карточка
  канала с историей эпизодов и формой решения диспетчера (`observe/dispatch/reject/clarify`).
  Текущая неисправность показана отдельно от прогноза — раздел 9.1 плана.
- Карта показывает только объекты с проверенной геометрией и явно считает объекты без
  координат отдельно (сейчас 0 из 95 — раздел 3.2 плана: без выдуманных координат).
- «Журнал»: список прогнозов, с явной пометкой устаревших (>24ч) записей.
- «Заявки»: список с фильтром по статусу, кнопки разрешённых переходов статуса
  (зеркалит `ALLOWED_TRANSITIONS` backend).
- Явные состояния загрузка/пусто/ошибка на каждой странице (`DataState`) — требование
  раздела 2 ТЗ MVP.
- Проверено на реальном сервере: `https://jkh.devcosmos.ru/` отдаёт фронтенд,
  `/api/*` — backend, TLS работает.

## Не реализовано (открыто)

- Данных в БД пока нет (только схема) — все страницы сейчас закономерно показывают пустое
  состояние. Наполнение — следующий шаг (импорт эпизодов/прогнозов из `docs/documentation/analysis/`).
- Автообновление в реальном времени — только кнопка «Обновить» (периодический опрос по
  требованию, а не поллинг по таймеру — можно добавить позже).
- Матрица доступа по объектам/подразделениям — сейчас только проверка роли.
- Мобильная адаптация не проверялась.
